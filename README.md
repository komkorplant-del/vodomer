# Водомер

Дневник воды, витаминов и мочеиспусканий. Открывается по ссылке, ставится на домашний экран айфона,
работает офлайн. Ни регистрации, ни сервера: все записи лежат в памяти браузера того устройства,
где вы их сделали.

**Открыть:** https://komkorplant-del.github.io/vodomer/

## Что делает

- **Вода.** Быстрые кнопки и поле для своего количества. Время подставляется само.
- **Мочеиспускание.** Одна кнопка; следом можно отметить цвет по шкале гидратации 1–6.
- **Витамины.** Список по времени с галочками; состав и часы настраиваются.
- **Итог дня** и столбики за неделю.
- **Выгрузка для чатов** — готовый текст со сводкой по дням для ChatGPT, Gemini или Claude, плюс CSV.
- **Резервная копия** в JSON и восстановление из неё.

## Уведомления

Приходят настоящими пушами. На iOS это работает только у приложения, добавленного на домашний
экран, поэтому порядок такой: открыть с иконки → «Настройки» → «Включить уведомления» → разрешить →
скопировать код подписки и один раз положить его в секрет репозитория `PUSH_SUBSCRIPTION`.

Расписание живёт не в телефоне, а в `schedule.json`, и рассылает его GitHub Actions по cron
(`.github/workflows/remind.yml`). Причина простая: iOS не даёт странице будить себя по таймеру,
разбудить её может только push извне. Времена считаются по Киеву, так что переход на зимнее
время расписание не сдвигает.

Что стоит знать: cron у GitHub Actions неточен, задержка обычно 5–15 минут; расписание не знает,
пили вы уже или нет, — напоминание придёт в свой час в любом случае; а если в репозиторий
60 дней не приходит ни одного коммита, GitHub усыпляет расписание.

Запасной вариант остаётся: в настройках печатается список времён для будильников в «Часах».

## Где данные

В `localStorage` браузера. Наружу ничего не уходит: сервера нет, аналитики нет, аккаунта нет.
Обратная сторона — очистка данных Safari или смена телефона стирает историю.
Раз в пару недель сохраняйте копию через «Настройки → Резервная копия».

## Устройство

Одна страница без сборки и зависимостей. `index.html` — разметка, стили и логика;
`sw.js` — офлайн-кэш; `manifest.webmanifest` — параметры установки на домашний экран.
События хранятся append-only списком по суткам (`days["ГГГГ-ММ-ДД"].events`),
удаление помечает запись флагом, слияние копий идёт объединением по `id` — поэтому
восстановление из бэкапа не плодит дублей. Сутки считаются с 04:00, чтобы ночной подъём
попадал в предыдущий день.
